# v0.21 Rubric Mapping

공식 PDF는 평가항목만 제시하며 배점은 공개하지 않았다. 아래 0~3은 공식 점수가 아닌 내부 readiness stress test다.

| 단계 | 공식 평가항목 | 직접/qualified evidence | 제한 | 내부 readiness |
| --- | --- | --- | --- | --- |
| 1 | 사업 적합성 | 대구 ON-A; 부여·울산 보조 | AMI 직접 field truth 아님 | 3 |
| 1 | 개발 용이성 | 실제 AMI 입력 + Flutter Web/Android | hardware 절감액 미산정 | 3 |
| 1 | Idea 창의성 | controller 독립 second-checker | confirmed-fault system 아님 | 2 |
| 1 | Idea 구체성 | actual data + workflow + artifact trace | field pilot 없음 | 3 |
| 2 | 개발 용이성 | Flutter app + deterministic preflight | production deployment 아님 | 3 |
| 2 | Idea 완성도 | Web/Android + tests + submission package | production 운영 아님 | 3 |
| 2 | 활용목적 | 점검 우선순위와 3-lane workflow | 정책효과 미실증 | 3 |
| 2 | 유형효과 | 반복·장기처리 workload와 ranking signal | 민원·비용 감소율 미산정 | 2 |
| 2 | 범용성 | 대구·부여·울산 운영 layer | 동일 schema/model 주장 아님 | 2 |

AMI 샘플 기반 APP 성과물은 공식 문서상 가점 요소지만 필수 제출물은 아니며 가점 수치는 공개되지 않았다.
