## Risks

- Large instructions can crowd out task evidence.
- Parallel agents can duplicate research or inherit the same confirmation bias.
- Agent self-report is weaker than generated registries, hashes, tests, and independent review.
- Literature and algorithms can look independent while sharing definitions selected after results.

## Adopted Rules

- Harness-first, repository-local record before edits.
- Freeze v0.11 before literature screening.
- Narrow TERRA/LUNA roles with disjoint files.
- Search protocol before result inspection.
- Literature, H1, proxies, and human review remain separate layers.
- Human labels are never generated by an agent.
- Artifacts and executable gates outrank agent summaries.
