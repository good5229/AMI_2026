# Terra Zero Shot Transfer

Freeze predictor semantics and eligibility before Buyeo outcome construction, train and select only in Daegu, then score untouched Buyeo once. Report AP, Top-10% enrichment, recall and asset-cluster uncertainty. Sources: [TRIPOD](https://doi.org/10.1136/bmj.g7594), [BMJ external-validation guide](https://www.bmj.com/content/384/bmj-2023-074820), [Saito-Rehmsmeier](https://doi.org/10.1371/journal.pone.0118432).
