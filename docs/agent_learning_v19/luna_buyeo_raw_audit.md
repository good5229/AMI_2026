# Luna Buyeo Raw Audit

Audit SHA, UTF-8-SIG schema, date failures, duplicates and original allowlisted fault labels. Export no complainant, location, detail, action text, receipt number or raw asset ID. Sources: [official Buyeo dataset](https://www.data.go.kr/data/15040580/fileData.do), [Korean Personal Information Protection Act](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900040612), [ISO 15489-1](https://www.iso.org/standard/62542.html).
