# Repository Agent Instructions

## Required startup order

1. If `harness_docs/` exists, read `harness_docs/index.md` first.
2. Apply the relevant files under `harness_docs/rules/` before changing code.
3. Read `harness_docs/dev-wiki/contract.md` and leave a backlog or log record before file changes.
4. Then load only the project files needed for the task.

`harness_docs` is the highest-priority repository-local operating guidance. It
must remain free of secrets and may be intentionally excluded from Git.
