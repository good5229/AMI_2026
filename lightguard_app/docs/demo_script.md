# LightGuard Demo Script (3~5분)

1. 문제 제기
- 자산+AMI를 함께 보며 점검 후보 우선순위를 제시해야 하는 유지관리 시나리오

2. Dashboard 확인
- 수영구 204개 분전함, 총 정격/정상/관찰/점검 수치 확인
- 실시간으로 점검 후보로 이동

3. 지도
- 분전함 마커 상태 표시
- 마커 선택 시 상세 화면 이동 확인

4. 점검 후보 목록
- 상태/등급 정렬 및 필터 확인
- 우선 점검 항목 확인

5. 분전함 상세
- 자산 정보, 예상 운전, 이상 근거, 점검권고를 한 화면에서 확인

6. 실제 AMI 사례
- B-L-35, B-L-9, B-L-14 같은 공모전 AMI 사례를 실제 AMI badge와 분리해서 표시

7. 지역 확장성
- 강릉/충주 모드 소개로 스키마 분산 대응성 확인

8. 종료
- 데이터 정직성 원칙: scenario와 실제 AMI의 경계를 설명
