# v0.8 Detector Validation

The 432-case independent controlled holdout did not promote a new detector. C1/C2 improved recall to 0.7315, but FPR 0.1111 exceeded the 0.05 gate. The production-facing baseline therefore remains frozen v0.4, while C1/C2/C3 are displayed only as failed experimental candidates. Weather remains context-only. Chungju rated load is unavailable with no imputation, and actual Gangneung/Chungju AMI performance remains unvalidated.
