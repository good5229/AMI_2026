# 충주 871개 분전함 부하·등기구 데이터 복원 조사

조사 기준일: 2026-08-20  
대상: `lightguard_app/assets/data/chungju_v02_seed.json`의 충주 분전함 871개  
목적: 현재 분전함 키를 공식 자료의 램프 종류, 소비전력, 안정기/LED 정격, 분전함 용량, 회로부하로 연결할 수 있는지 판정

## 결론

현재 공개된 충주시 원자료만으로는 871개 분전함별 정격부하를 복원할 수 없습니다. 현재 데이터는 분전함 단위 식별·위치·등주수량 데이터이며, 개별 등기구 식별자와 전기 사양 또는 회로별 부하가 없습니다.

조달 문서에서 일부 사업의 `LED 150W 이하`, `컨버터 80/60W`, `분전함 지주형 4회로`, `누전회로 탐사 분전함 기준` 같은 규격은 확인되지만, 이는 특정 공사의 설계·내역 범위이지 871개 전체의 현행 자산 사양이나 특정 분전함의 사실값이 아닙니다. 따라서 해당 값을 충주 전체에 적용하거나 등주수량에 곱하지 않습니다.

## 현재 공식 키와 보유 필드

공공데이터포털의 2026-06-30 파일은 전체 871행이며 다음 필드를 공개합니다.

| 필드 | 현재 상태 | 871개 전체 공식 연결에 사용 가능 여부 |
|---|---|---|
| 분전함 번호 | 있음 | 가능. 1차 공식 키 |

| 등주수량 | 있음 | 가능. 연결된 등주 수량일 뿐, 램프 수·와트수와 동일하지 않음 |

## 필드별 복원 가능성 분류

분류는 “지금 871개에 대해 공식 키로 연결 가능한가”를 기준으로 한다. 조달 문서에 해당 용어가 한 번 등장했다는 사실은 개별 자산 연결의 증거로 세지 않는다.

| 복원 대상 | 분류 | 확인된 근거 | 정확한 확보 경로 |
|---|---|---|---|
| 분전함 ID·명칭·위치·등주수량 | `RECOVERABLE_OFFICIAL` | 충주시 공개 파일의 871행 및 필드 정의 | 공공데이터포털 파일/API를 기준 데이터로 사용. 최신 기준일자 재다운로드 후 ID·명칭·좌표를 원본 그대로 보존 |
| 램프 종류 | `PARTIALLY_RECOVERABLE` | 충주시 조달 공고는 LED 보안등 교체 사업과 설계도서 열람을 안내하지만 871개별 램프 종류를 공개하지 않음 | 충주시 도로과에 분전함 번호를 포함한 등기구 대장/준공도면/교체 이력 요청. 각 행은 `cabinet_no -> fixture_id -> lamp_type -> evidence_document`로 확인될 때만 채움 |
| 램프·LED 소비전력(W) | `PARTIALLY_RECOVERABLE` | 조달 원가계산서에 특정 유지보수 공사의 `LED150W 이하`가 나타나나 개별 분전함 매핑은 없음 | 해당 공사의 설계내역서, 물량내역서, 자재승인서, 준공검사서와 대상 위치 목록을 함께 확보. `이하` 범위를 실제 정격값으로 해석하지 않음 |
| 안정기·컨버터 정격 | `PARTIALLY_RECOVERABLE` | 조달 문서에 `컨버터 80/60W`와 관련 교체 공종이 기재됨 | 도로과·계약담당에 공사별 자재승인서와 준공자료를 요청하고, 제조사 모델/정격이 분전함·등기구 ID에 연결된 행만 채움 |
| 분전함 용량·회로 수 | `PARTIALLY_RECOVERABLE` | 특정 지중선로 유지보수 내역에 `지주형, 4회로` 분전함 설치·철거가 기재됨 | 871개별 단선결선도, 분전함 명판 사진, 차단기 목록, 회로대장, 준공도면 요청. 특정 공사의 4회로 규격을 전체에 전이하지 않음 |
| 회로별 정격부하(kW) | `NOT_RECOVERABLE` | 공개 871행에는 회로·차단기·전력값이 없고, 조달 문서도 공사 범위·규격 중심임 | 도로과/전기안전관리자에게 회로대장·단선결선도·시험성적서·최근 안전점검 기록을 요청. 실제 부하는 별도 계측 또는 승인된 AMI/검침 데이터가 필요 |
| 분전함-AMI/전력계량기 매핑 | `NOT_RECOVERABLE` | 현재 프로젝트에는 충주 실제 AMI와 871개 분전함의 공식 매핑이 없음 | 충주시와 전력공급자/AMI 운영기관의 자산번호 대조표, 계량기 번호, 수전점, 검침구간, 개인정보·보안 검토 결과를 서면으로 확보 |

### 분류 해석

- `RECOVERABLE_OFFICIAL`: 현재 공식 공개 원자료에 필드와 키가 있으며, 재현 가능한 방식으로 그대로 회수 가능하다.
- `PARTIALLY_RECOVERABLE`: 공식 설계·계약·준공 자료에 일부 대상 또는 사업의 값이 있을 가능성이 확인되지만, 현재 871개 전체에 대한 공개 키 연결은 없다.
- `NOT_RECOVERABLE`: 현재 공개자료와 확인된 조달 자료만으로는 자산별 값을 산출하거나 연결할 수 없다. 별도 기관 보유자료, 현장 확인 또는 승인된 계측이 필요하다.

## 조사에서 확인한 공식 자료

### 공공데이터포털 / 충주시 원자료

[충청북도 충주시 가로등분전함정보](https://www.data.go.kr/data/15041822/fileData.do?recommendDataYn=Y)는 제공기관을 충청북도 충주시로 명시하고, 전체 행 871개, CSV 및 API, 연간 업데이트를 안내한다. 필드는 분전함 번호, 설치위치, 분전함 이름, 등주수량, 관리기관, 위도, 경도, 데이터기준일자다. 포털은 자세한 유지관리 이력과 전기안전 점검 내용은 충주시청 도로과 등 관련 부서를 통해 확인해야 한다고 명시한다.

공개 API 명세는 [ODcloud API 문서](https://infuser.odcloud.kr/oas/docs?namespace=15041822/v1)에서 확인된다. 이 API는 현재 공개된 필드의 재수집 경로이지, 비공개 정격부하를 제공하는 API가 아니다.

충주시 공식 스마트도시계획에도 가로등 분전함 데이터가 `분전함ID, 행정동, 설치위치, 이름, 등주수량, 위도, 경도` 수준으로 소개된다. [충주시 스마트도시계획 2024-2028](https://smartcity.go.kr/wp-content/uploads/2025/01/%EC%B6%A9%EC%A3%BC%EC%8B%9C-%EC%8A%A4%EB%A7%88%ED%8A%B8%EB%8F%84%EC%8B%9C%EA%B3%84%ED%9A%8D_24.12.pdf)

### 충주시·나라장터 조달 자료

[2026년 호암직동 외 1개동 LED 보안등 및 등주 교체공사 공고 첨부 PDF](https://www.g2b.go.kr/pn/pnp/pnpe/UntyAtchFile/downloadFile.do?bidPbancNo=R26BK01487209&bidPbancOrd=000&fileSeq=2&fileType=&prcmBsneSeCd=07)는 충주시 호암직동·칠금금릉동의 LED 보안등 80개소 및 등주 8개소 교체를 명시한다. 공고는 설계도서를 담당 부서에 비치하고 열람으로 갈음한다고 안내한다. 이는 설계도서가 핵심 증거라는 뜻이지만, 공고문 자체가 871개 전체의 현행 자산 사양을 제공하지는 않는다.

[2026년도 가로등 유지보수(지중선로) 원가계산서](https://www.g2b.go.kr/pn/pnp/pnpe/UntyAtchFile/downloadFile.do?bidPbancNo=R26BK01450767&bidPbancOrd=000&fileSeq=6&fileType=&prcmBsneSeCd=07)는 LED150W 이하, 컨버터 80/60W, 분전함 지주형 4회로, 분전함 기준 누전회로 탐사 등의 공종·규격을 보여준다. 이 값들은 해당 계약의 작업 기준이며, 충주 871개 자산의 일괄 정격값으로 사용하지 않는다.

### 예산·지방의회 자료

[충주시의회 2026년 제1회 추가경정예산 심사 결과](https://council.chungju.go.kr/minutes/svc/web/cms/mnts/SvcMntsViewer.php?mode=spkr1&schSn=4049&spkrCd=MBR9060)는 예산안이 의회 심사·의결 대상임을 확인하는 공식 기록이다. 예산 편성·심의 자료는 조명 교체·유지보수 사업의 존재와 사업 범위를 확인하는 보조 근거로 사용하되, 자산별 기술대장이나 준공 매핑의 대체 자료로 사용하지 않는다.

## 정확한 데이터 확보 절차

### 1단계: 공개 원자료 재확인

1. 공공데이터포털에서 최신 CSV/API를 내려받는다.
2. `분전함 번호`를 불변 원키로 보존하고, 이름·주소·좌표는 원문과 정규화 값을 별도 보관한다.
3. 871개 행의 중복·누락·기준일자를 점검한다.
4. `등주수량`은 수량 정보로만 사용하고 정격부하 계산에 직접 사용하지 않는다.

### 2단계: 충주시 보유자료 요청

공공데이터포털의 관리부서 정보와 데이터 한계를 근거로, 충주시 정보공개 또는 공공데이터 제공 신청을 다음 범위로 제출한다.

- 대상키: 공개 파일의 `분전함 번호` 871개 전체
- 요청 필드: 등기구/등주 ID, 램프 종류, 소비전력·정격 W, 안정기/컨버터 모델·정격, 분전함 정격·회로수, 회로별 차단기 정격, 단선결선도, 준공도면, 최근 교체·보수 이력
- 필수 조인키: `분전함 번호` 또는 원자료와의 대응표. 주소·좌표만으로 추정 매칭하지 않음
- 증거 메타데이터: 문서번호, 계약번호, 공사기간, 기준일, 대상 위치 목록, 원문 페이지/행, 제공기관 확인자
- 반환 형식: CSV/JSON 우선, 도면·증빙은 PDF와 파일 해시를 함께 요청

공개데이터법은 공공기관이 보유·관리하는 공공데이터의 제공 신청 경로를 규정한다. [공공데이터의 제공 및 이용 활성화에 관한 법률](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=218743) 제27조의 신청 취지를 적용하되, 특정 문서의 공개 여부는 기관의 개별 판단을 따른다.

정보공개청구는 [정부24 정보공개청구 안내](https://m.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13110000037&HighCtgCD=A02003)를 통해 인터넷·방문·우편·FAX로 신청할 수 있고, 안내상 처리기간은 총 20일이다. 청구 대상 기관은 충주시청으로 지정하고, 포털에 표시된 정보통신과 전화 `043-850-5312`를 데이터 라우팅 문의에 사용한다. 유지관리·전기안전 점검 자료는 포털 안내대로 도로과에 병행 문의한다.

### 3단계: 조달·준공 자료 조인

나라장터에서 충주시 도로조명·LED·보안등·분전함 사업을 계약번호로 수집한다. 공고서만으로 확정하지 않고 다음 자료를 한 묶음으로 확보한다.

```text
공고/계약번호
-> 설계도서·시방서
-> 물량내역서
-> 자재승인서·납품서
-> 위치별 작업목록
-> 준공도면·준공검사서
-> 분전함 번호/등기구 ID 대응표
```

위치별 대응표가 없으면 해당 조달 규격은 `PARTIALLY_RECOVERABLE` 근거로만 유지한다.

### 4단계: 전기안전·부하 자료 조인

전기안전 자료는 램프 모델 목록과 동일하지 않다. 정격·회로부하를 복원하려면 분전함별 단선결선도, 차단기 명세, 검사·시험기록, 측정 시점과 부하 조건이 함께 필요하다. [전기안전관리법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=271295)은 한국전기안전공사의 전기설비 검사·점검 및 기술지원 업무를 규정한다. [KESC 전기설비 검사·점검기준](https://law.go.kr/LSW/flDownload.do?flSeq=143527963)은 검사·점검의 기준 문서이지, 충주 871개 자산 데이터를 공개하는 자료는 아니다.

| blocker | 영향 | 해소 조건 |
|---|---|---|
| 현재 공개 파일에 등기구·회로 사양 없음 | 871개별 W/kW 계산 불가 | 충주시 도로과 보유 대장·설계·준공 자료 제공 |
| 조달 공고 규격이 위치별 대상과 분리됨 | LED150W/컨버터 80/60W를 자산 사실로 승격 불가 | 계약번호별 위치목록·준공 매핑 확보 |
| 설계도서는 공고문상 부서 열람 방식 | 원격 자동 수집 및 재현성 제한 | 담당 부서 열람/사본 제공 승인 또는 정보공개 결정 |
| 전기안전·계량 자료의 기관/소유자 제한 가능성 | 회로부하·AMI 링크 검증 보류 | 충주시 소유자 승인, 전기안전관리자·전력공급자 제공 범위 확인 |
| 개인정보·보안·시설보호 검토 | 도면·계량기 번호의 부분 비공개 가능 | 비식별화된 키 대응표와 최소필드 제공 협의 |
| 현장 기준일 불일치 | 교체 전후 사양 혼합 위험 | 모든 행에 기준일·공사기간·준공일 부여 |

## 앱 반영 경계

자료가 확보되기 전까지 충주 화면은 다음 정책을 유지한다.

- `lamp_count`는 공개 원자료의 등주수량으로 표시한다.
- `rated_power_w`와 예상 정격부하는 `unavailable_no_imputation`으로 표시한다.
- 조달 규격이나 다른 지역 평균을 충주 분전함에 복사하지 않는다.
- 등주수량 × 임의 와트 계산을 하지 않는다.
- 충주 분전함에 실제 AMI 이상을 연결하지 않는다.
- 외부 자료가 확보되면 문서번호·계약번호·원문 행까지 추적 가능한 증거가 있는 행만 부분적으로 승격한다.

## 최종 판정

현재 시점의 871개 충주 분전함별 정격부하 복원은 `NOT_RECOVERABLE`이다. 다만 공식 설계·준공·유지관리 자료가 분전함 번호와 함께 제공될 경우 램프 종류·와트·안정기/컨버터·회로수는 `PARTIALLY_RECOVERABLE`에서 대상 행 단위로 승격될 수 있다. 회로별 실측부하와 AMI 매핑은 별도 계측·기관 승인 없이는 복원할 수 없다.
